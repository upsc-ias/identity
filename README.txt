SENTINEL // MBTI TYPE ATLAS

Open index.html in a current browser. The project includes all 16 type profiles, preference-pair summaries, strengths, and possible growth edges. Choose a type from the directory to view its profile. Drag the human scan with a mouse, finger, or pen; it slowly auto-spins by default.

This is an educational overview, not an MBTI assessment or a description of every person who prefers a type. Type preferences are not ability or destiny. For official descriptions, see the links in the page footer.

The human mesh is bundled in model-data.js. Three.js and the optional fonts load from CDNs, so internet access is needed.

The four active type letters color the model as a blended head-to-foot gradient. Each MBTI letter has a fixed color shown in the preference-pair legend.

The Identity Selector buttons show the type name first and the four-letter code beneath it. The profile's letter color key explains all eight preferences and the reason for each color.
